# Intra Aura Admin CMS upgrade

New admin features:
- /admin/website — edit Header, Home, About, Services, Portfolio and Contact content.
- /admin/media — upload reusable JPG/PNG/WEBP site images, copy their paths, and delete uploaded site media.
- Existing Products, Product Images, Categories and Enquiries admin functionality remains available.
- Website content is stored in app/content/site_content.json, so no database migration is required.
